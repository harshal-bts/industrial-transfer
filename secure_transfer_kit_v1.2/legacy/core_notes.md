# Industrial secure data transfer – reference prototype

For engineering exploration only. Do not deploy on industrial equipment. Python 3.10+ and cryptography required. Install dependencies in a separate development environment; run `python transfer_demo.py ./test-runs`. Each invocation creates a new test tree and retains it. No file deletion, formatting, move, or overwrite function is included. The simulated USB is an ordinary test directory, NOT a real device.

Demonstrates per-chunk optional zlib compression, AES-256-GCM encryption, RSA-OAEP SHA-256 key wrapping, Ed25519-signed outer manifest, encrypted inner manifest, SHA-256 integrity, create-only copying, idempotent forwarding of intact chunks, decryption to quarantine, and signed quarantine status. Quarantine verification is NOT a production commit or authorization to remove USB data.

Production gaps: implement OEM-approved export snapshot, source/device identity and key binding, persistent secure key provisioning/rotation, server database and atomic durable commit, quotas, strict manifest schema and limits, complete case/path collision validation, OS handle-based directory confinement (checks in this example are not race-proof), OS-enforced local ACLs and no-delete policy, transport (mTLS HTTPS / SFTP), malware scanning, source and destination format validation, durable audit and signed COMMITTED receipt. Add retries using immutable attempt names for incomplete/conflicting chunks; current example skips intact existing chunks but stops on a conflict. Interrupted package creation is retained and requires a new package attempt; interrupted quarantine extraction requires a separate quarantine attempt if a partial file exists. Use a disk capacity gate before starting; never auto-purge local files. Test on actual OS and OEM-approved hardware before rollout.

USB cleanup intentionally not implemented. Implement only on the dedicated workstation with a separate restricted service using OS-native device/volume identity checks, handle-based confinement, signed COMMITTED receipt verification, inventory matching, exact file allowlist and revalidation; prohibit recursive cleanup and formatting. The exporter has no deletion capability, including USB deletion. No user-selectable flag may disable this policy.
